# Dados

O CSV não está no repositório: tem cerca de 144 MB, acima do limite de 100 MB por arquivo do GitHub, e é uma base pública.

1. Baixe `creditcard.csv` em https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
2. Salve em `data/creditcard.csv`.
3. Confira: 284.807 linhas, 31 colunas e 492 linhas com `Class == 1`.

Créditos: Machine Learning Group, Université Libre de Bruxelles (ULB), e Worldline.
